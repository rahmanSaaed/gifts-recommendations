# Gift Genie

Gift Genie is a small full-stack app that suggests thoughtful gift ideas. You describe the person you're shopping for, and the app streams back gift recommendations generated by an AI model (with web search for up-to-date products).

## Tech stack

- **Frontend:** React 19 + Vite, `marked` for Markdown rendering, `dompurify` for sanitizing output
- **Backend:** Node.js + Express 5, OpenAI SDK (Chat Completions and Responses APIs), Swagger UI for API docs

## Project structure

```
gifts-recommendations/
├── backend/
│   ├── openapi.yaml          # API documentation (served at /api-docs)
│   └── src/
│       ├── server.js         # Express server and API routes
│       ├── giftGeniePrompt.js # System prompts and examples
│       └── giftSchema.js     # JSON schema for structured gift output
└── frontend/
    └── src/
        ├── App.jsx           # Main UI
        └── main.jsx
```

## Getting started

### Prerequisites

- Node.js 20 or newer
- An API key for an OpenAI-compatible provider

### 1. Backend

```bash
cd backend
npm install
```

Create a `backend/.env` file:

```env
AI_KEY=your_api_key
AI_URL=https://api.openai.com/v1
AI_MODEL=gpt-4o-mini
PORT=5050
```

Start the server:

```bash
npm run dev    # with auto-reload (nodemon)
# or
npm start
```

The API runs on `http://localhost:5050` and the Swagger docs are available at `http://localhost:5050/api-docs`.

### 2. Frontend

```bash
cd frontend
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## API endpoints

| Method | Endpoint                  | Description                                          |
| ------ | ------------------------- | ---------------------------------------------------- |
| POST   | `/api/gift-genie`         | Main endpoint: streams gift suggestions as Markdown  |
| GET    | `/api/gifts`              | Static sample list of gifts                          |
| GET    | `/api/ai-test`            | Simple AI connection test                            |
| GET    | `/api/ai-followup`        | Two-turn conversation demo                           |
| GET    | `/api/stream-test`        | Streaming demo                                       |
| GET    | `/api/responses-test`     | Responses API demo                                   |
| GET    | `/api/gift-json`          | Structured JSON output using a schema                |
| GET    | `/api/gift-json-native`   | JSON output without a schema (for comparison)        |
| GET    | `/api/web-search-test`    | Web search tool demo                                 |

Example request:

```bash
curl -N -X POST http://localhost:5050/api/gift-genie \
  -H "Content-Type: application/json" \
  -d '{"userPrompt": "my dad loves fishing"}'
```
